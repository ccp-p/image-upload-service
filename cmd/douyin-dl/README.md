# douyin-dl

A small Go CLI that resolves a Douyin (TikTok CN) video URL into direct
download links. A Go port of the download pipeline from
[jiji262/douyin-downloader](https://github.com/jiji262/douyin-downloader).

## Build

```bat
go build -o cmd/douyin-dl/douyin-dl.exe ./cmd/douyin-dl
```

## Usage

Double-click `cmd\douyin-dl\run.bat` (or run it from a terminal), then paste a
Douyin link. Build the exe first so `run.bat` can find `douyin-dl.exe`.

```bat
run.bat
:: or pass the URL directly:
run.bat https://www.douyin.com/video/7380308675841297704
```

You can also pipe a URL (or full share text) via stdin:

```bat
echo https://www.douyin.com/video/7380308675841297704 | douyin-dl.exe
```

Accepted inputs: full `www.douyin.com/video/<id>` URLs, `modal_id=<id>` URLs,
`v.douyin.com` short links, or raw share text containing a short link.

## Cookies

The Douyin web API rejects anonymous requests. Save your browser cookies to a
`cookies.txt` file (one line, `k=v; k2=v2; ...` format) in the same directory.
Place it at `cmd/douyin-dl/cookies.txt` (next to `run.bat`).
The important keys are: `ttwid`, `odin_tt`, `passport_csrf_token`, `msToken`.

In Chrome DevTools -> Application -> Cookies -> https://www.douyin.com, copy the
full cookie string and paste it into `cookies.txt`.

## How it works

1. **URL parse** -- extract the `aweme_id` from the URL (or resolve a short
   link via HTTP redirect).
2. **ABogus sign** -- the `/aweme/v1/web/aweme/detail/` API requires an
   `a_bogus` signature parameter. This is generated by porting the Python
   `ABogus` class (SM3 + RC4 + custom Base64 + browser fingerprint).
3. **Detail API** -- `GET /aweme/v1/web/aweme/detail/?aweme_id=<id>&aid=6383`
   returns the video metadata JSON.
4. **Extract play URLs** -- from `aweme_detail.video.bit_rate[].play_addr.
   url_list`, preferring the highest-resolution watermark-free CDN mirror.
   Falls back to a signed `/aweme/v1/play/` URL if no direct mirror exists.

## Files

| File | Purpose |
------|---------|
| `sm3.go` | Pure Go SM3 hash (GB/T 32905), used by ABogus |
| `abogus.go` | ABogus signature port (SM3+RC4+Base64+fingerprint) |
| `client.go` | HTTP client, default query params, signed URL construction |
| `urlparse.go` | URL type detection, video ID extraction, short URL handling |
| `detail.go` | Detail API call + play URL extraction |
| `main.go` | CLI entry point |
| `run.bat` | Windows launcher |
| `verify_abogus.py` | Cross-validation against the original Python (needs gmssl) |

## Cross-validation

To verify the Go ABogus port matches the original Python byte-for-byte:

```bat
pip install gmssl
python verify_abogus.py
```

The output must match the `a_bogus` value logged by:

```bat
go test -run TestABogusDeterministic -v
```
